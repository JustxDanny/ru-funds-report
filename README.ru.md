# ru-funds-report

**Телеграм-бот, который держит инвестора рядом с его фондами.**

*[Read in English →](README.md)*

---

## Задача

Мой друг вкладывается в российские ПИФы. Управляющие присылают ему отчёт **раз в
месяц**. Пока отчёт доходит, цифры успевают устареть: он реагирует на то, что
уже произошло.

Терминал трейдера ему не нужен. Ему нужен ответ на один вопрос, два раза в
неделю, в приложении, которое и так открыто:

> *«Что с моими фондами с тех пор, как я смотрел в прошлый раз?»*

## Решение

Каждый понедельник и пятницу утром задача просыпается, забирает текущую
стоимость пая по десяти фондам, которыми он реально владеет, считает изменение,
собирает аккуратный Excel и кладёт его ему в Telegram.

Ничего не надо ставить. Никаких логинов. Никакой панели, в которую надо не
забыть зайти. Отчёт просто приходит.

```
  Пн / Пт 09:00
        │
        ▼
  два сайта фондов  ──►  считаем Δ% по дням и накопленным итогом
        │                            │
        │                            ▼
        │                   помечаем странное
        ▼                            │
   собираем .xlsx  ◄─────────────────┘
        │
        ▼
   📲 Telegram
```

## Что он получает

Excel в две колонки, по-русски, читается за десять секунд:

- **Синяя половина**: фонды с wealthim.ru. **Зелёная**: с first-am.ru.
- Строка на каждый торговый день: изменение за день и накопленное за период.
- Всё необычное (движение больше 3% или данные, которые не обновились) **помечено
  прямо в таблице**, мимо не пройдёшь.

## Попробовать

```bash
git clone https://github.com/JustxDanny/ru-funds-report
cd ru-funds-report
python -m pip install -e .

cp .env.example .env                        # вписать токен телеграм-бота
python -m funds_report --days 4 --no-send   # сухой прогон: печатает путь к xlsx
python -m funds_report                      # боевой прогон: отправка в Telegram
```

`--days` выбирается сам по дню недели (1 в понедельник, 4 в пятницу, 5 иначе).
Передайте число, чтобы переопределить.

**Нужно:** Python 3.11+ и токен бота от [@BotFather](https://t.me/BotFather).

## Запуск по расписанию (Windows)

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\install_task.ps1
```

Ставит задачу в планировщик на понедельник и пятницу, 09:00. `WakeToRun`
включён: спящий компьютер проснётся к запуску. Логи в `logs/`. Снять:
`schtasks /delete /tn funds-report /f`.

## Как устроено

```
data/funds.yaml ──► config.py     какие фонды и что считать «странным»
                       │
                       ▼
        scrape.py ──► parsers.py  забрать страницы → список (дата, цена)
                       │
                       ▼
                   metrics.py     Δ% за день, накопленный Δ%, флаги аномалий
                       │
                       ▼
                   excel.py       та самая двухколоночная таблица
                       │
                       ▼
                   notify.py      Telegram sendDocument, несколько получателей
                       │
                       ▼
                     cli.py       оркестрация, логи, коды возврата
```

Парсеры чистые функции: на входе байты, на выходе Decimal. Ни часов, ни сети в
тестах, поэтому весь набор проходит офлайн примерно за одну пятую секунды.

```bash
python -m pytest      # 22 теста, ~0,2 с, без сети
```

## Четыре решения, которые я готов защищать

**Decimal, а не float.** Вся арифметика по стоимости пая идёт через
`decimal.Decimal`. Итог считается двумя независимыми способами (прямое отношение
и произведение дневных коэффициентов), и они обязаны сойтись с точностью
0,0001%, иначе прогон падает. По этим числам человек принимает решения о
деньгах; «примерно верно» здесь не годится.

**Никакого ИИ в рантайме.** Первый прототип забирал страницы через ИИ-CLI. Он был
недетерминирован: иногда молча скатывался к сниппетам из поиска вместо реальных
данных. Для демо сойдёт; для числа, по которому человек действует, нет.
Заменено на обычный regex и разбор JSON. *ИИ помог мне это построить, но внутрь
он не попал.*

**Падать громко, а не ошибаться тихо.** Плохая цена, переставший совпадать
парсер, устаревшие данные: всё бросает исключение и останавливает прогон.
Непришедший отчёт заметят. Отчёт, который уверенно пишет «+0,00%» про фонд,
который на самом деле упал, наносит настоящий вред.

**Брать данные с самого чистого слоя.** wealthim.ru рисует на странице два знака
после запятой, но отдаёт скрытый экспорт `xlsx.php` с четырьмя. Нашлось чтением
скрытой формы на самой странице. first-am.ru встраивает всю историю как
JSON-литерал внутри `<script>`, поэтому мы разбираем его, а не отрисованную
таблицу. Оба варианта ближе к источнику и переживут редизайн страницы.
